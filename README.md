# WE-CFM-Orchestrator

WE-CFM-Orchestrator is an Electron-based crypto prediction and orchestration app focused on 15-minute Kalshi market analysis, live signal aggregation, and adaptive model tuning.

- Real-time multi-source signal pipeline (crypto exchanges + prediction markets)
- Adaptive weighting and regime-aware tuning
- Desktop workflow for monitoring, analysis, and execution

Project page: https://github.com/JohnDaWalka/WE-CFM-Orchestrator
